## 한눈에 보기: 보완 후 무엇이 달라졌나

| 팀 결과 | 보완 후 |
|---|---|
| 고령운전자 사고 +22.3%, 반납률 −8.5% | 유지. 면허 소지자 기준 반납률은 **−14.0%**로 더 크게 줄었고, 사고 증가는 주로 **고령 면허 소지자 증가(+17.8%)** 때문(면허 소지자 1만 명당 사고는 +3.8%) |
| 정류장 많을수록 반납률 낮음 (r = −0.72 ~ −0.81) | **튼튼함.** 원자료 급변값을 6가지로 처리해도 r = −0.66 ~ −0.88 |
| "정류장 수가 아니라 버스가 얼마나 자주 오느냐" | **확인되지 않은 가설.** 배차간격 만족도는 대도시·도 차이 없음(4.52 vs 4.52), 반납 지원 조례 보급률도 설명력 없음(\|r\| < 0.4). 반납률은 **대도시 vs 도**로 가장 일관되게 갈림 |
| 기대 효과: 5,760명 · 사고 27건 · 2.6억 원 (단일 추정) | 공식 통계로 재계산한 범위: 중간 시나리오 **10,119명 · 사고 0~83건 · 0~28.3억 원** (가정 1개 공개) |
| 정부 대책 6건 (2022~2024) | 정부 48건(2015~2025) · 지자체 조례 182건 · 국회 법안 40건 — 모두 **면허·보행 중심, 이동권 대책은 드묾** (팀 판단 재현) |
| 치사율 가설(A-2) | 배경 근거로 이동. 주제에 맞춘 새 가설(반납률 ↔ 사고 증가율)도 기각 — 반납과 사고는 시도 단위에서 연결되지 않음 |

## 실행 방법

모든 코드는 저장소 최상위에서 실행한다.

```bash
python "개선/01_기대효과/기대효과_재설계.py"
```

- API를 쓰는 코드(`05_조례`, `06_법안`)는 각 폴더에 인증키 파일(`oc.txt`, `key.txt`)이 있어야 한다. 인증키는 `.gitignore`로 저장소에 올리지 않는다.
- 필요한 패키지: pandas, numpy, scipy, matplotlib, seaborn, requests, beautifulsoup4, pymupdf

## 데이터 원칙

- 출처는 **공공데이터포털, KOSIS, TAAS, 정부·공공기관 공식 보고서, 공식 Open API**만 사용한다. 신문 기사는 근거로 쓰지 않는다.
- 수집 전 robots.txt를 확인하고, 수집이 막힌 곳(국회 의안정보시스템 등)은 공식 API를 쓴다. 요청 사이에는 간격을 둔다.
- 결과를 본 뒤 가설을 바꾸지 않는다. 기준선 근처 결과는 이상값 제외·순위 상관으로 안정성을 함께 확인한다.
